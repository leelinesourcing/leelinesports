# Phase 2: Page Structure Template

The 11-section structure with differentiation strategy. Sections may be added, removed, or reordered based on business type and existing project pages.

---

## Default 11-Section Layout

```
1.  Hero
2.  Pain Points
3.  What We Deliver
4.  How It Works
5.  Our Team (optional)
6.  Real Results
7.  Who This Is For
8.  Why We're Different
9.  What Clients Say
10. FAQ
11. Final CTA
```

## Section Details

### 1. Hero
**Purpose**: Communicate value proposition in under 5 seconds
**Elements**:
- H1 (Title formula: keyword + differentiator + credibility)
- Subtitle (1-2 sentences, pain + solution preview)
- Primary CTA button
- Secondary CTA link
- Trust signal strip (logos, numbers, certification badges)
- Hero image/illustration (right side or background)
**Background**: Full-width, brand primary or dark

### 2. Pain Points
**Purpose**: Validate the visitor's frustration
**Elements**:
- Section header: "The [Problem] Keeping [Audience] Up at Night" or a buyer question
- 3-4 pain cards, each with icon + specific scenario
- Closing sentence: "This is why [Company] exists."
**Background**: Light gray or brand secondary-light

### 3. What We Deliver
**Purpose**: Show the solution with parameters
**Elements**:
- Section header: Title formula
- 3-4 offering cards
- Each card: icon + title + pain resonance → solution with numbers → trust
**Background**: White

### 4. How It Works
**Purpose**: Make the process feel achievable
**Elements**:
- Section header: "How [Company] Delivers [Outcome] in [Timeframe]"
- 3-4 numbered steps
- Each step: number + title + 1-2 sentence description + timeline
- Optional: simple flow illustration
**Background**: Light gray or brand accent-light

### 5. Our Team (Optional)
**Purpose**: Build trust through expertise credentials
**Elements**:
- Section header
- 2-4 team member cards (photo, name, title, key expertise)
- Only include if team is a differentiator (not for freelancers/solopreneurs)
**Background**: White

### 6. Real Results
**Purpose**: Prove value with evidence
**Elements**:
- Section header: "[Number]+ [Outcome] Delivered for [Audience]"
- 1-2 mini case studies in card format
- Expandable to full case study if desired
- Each case: company name/industry → problem → solution → quantified result
- Result must include: before/after metric + timeframe
**Background**: Light gray or brand secondary-light

### 7. Who This Is For
**Purpose**: Help the visitor self-identify as a qualified prospect
**Elements**:
- Section header: "[Service] Works Best for [Audience Type]"
- 3-4 profile cards
- Each: role + primary pain + why this fits
- Optional reverse section: "This Is Not for You If..." (disqualification)
**Background**: White

### 8. Why We're Different
**Purpose**: Overcome competitor-comparison objection
**Elements**:
- Section header: "What Makes [Company] Different"
- 3-4 comparison points
- Each: competitor approach vs our approach + specific benefit
- Include 1 unique capability competitors cannot replicate
**Background**: Brand primary or dark (inverted colors)

### 9. What Clients Say
**Purpose**: Social proof with specifics
**Elements**:
- Section header: "What [Audience] Say About Working with [Company]"
- 2-3 testimonial cards
- Each: quote + name + title + company + photo (if available)
- At least 1 testimonial with a specific metric
**Background**: Light gray

### 10. FAQ
**Purpose**: Answer remaining objections without pressure
**Elements**:
- Section header: "Answers to Common Questions"
- 5-8 questions in accordion format
- Questions drawn from buyer question list (interview Section B)
- Topics: process, timeline, pricing, compatibility, support, results
- Each answer: direct (1 sentence) + detail (1-2 sentences) + optional evidence
**Background**: White

### 11. Final CTA
**Purpose**: Convert visitors ready to act
**Elements**:
- Value restatement (1 sentence)
- Primary CTA button (same as Hero, possibly stronger)
- Secondary CTA as text link
- Lead magnet offer below (optional)
- Contact info if relevant (phone, email)
**Background**: Brand primary or dark

## Background Color Alternation Pattern

Default pattern (may be overridden by brand guide):

```
Hero:       Brand-primary or dark
Pain:       Light gray (gray-50/gray-100)
Deliver:    White
How It Works: Light gray
Team:       White
Results:    Light gray
Who For:    White
Different:  Brand-primary or dark (inverted)
Testimonials: Light gray
FAQ:        White
CTA:        Brand-primary or dark
```

For differentiation from existing site pages, shift the pattern:
- If existing pages use gray on section 2, use brand-tinted background instead
- If existing pages use white backgrounds, introduce subtle brand gradients
- Alternate card layouts (existing use left-aligned cards → use centered or grid)

## Differentiation Strategy

When analyzing existing pages in Phase 0, check these dimensions:

| Dimension | What to Check | Differentiation Tactic |
|-----------|---------------|----------------------|
| Section order | Do existing pages use a similar pattern? | Rearrange; insert missing sections (Who This Is For, Real Results) |
| Background pattern | Does the site always use gray/white alternating? | Shift the pattern; add brand-tinted sections |
| Card style | Cards with icons? Bordered? Shadow? | Use a different card style (shadowless, bordered, or elevated) |
| Hero format | Centered text? Left-aligned? Full-screen? | Use the opposite format |
| CTA style | Button shape, color, placement | Different button treatment |
| Typography | Heading sizes, font choices | Vary heading hierarchy |
| Section count | How many sections on existing pages? | Use more or fewer sections |

### Section Innovation Options

If the project's existing pages lack certain section types, prioritize adding:
- **Pain Points** section (often missing, highly effective)
- **Who This Is For** + disqualification (sophisticated positioning)
- **How It Works** with numbered steps (reduces anxiety)
- **Why We're Different** direct comparison (handles competitor research phase)

### Layout Variation Ideas

- **Alternating image side**: Even sections image-left, odd sections image-right
- **Full-width backgrounds on alternate sections**: Creates visual rhythm
- **Staggered cards**: Instead of equal grid, use 2+1 or 1+2 card layouts
- **Timeline visualization**: For How It Works, use horizontal timeline instead of cards
- **Split hero**: Left text + right visual instead of centered text
- **Masonry testimonials**: Different sized testimonial cards for visual interest
